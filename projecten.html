Mijn portfolio website

Dit is een van mijn projecten tijdens de opleiding Software Development.

Voor dit project heb ik vijf verschillende pagina's gemaakt: Home, Over mij, Vaardigheden, Projecten en Contact.

Ik heb deze website zelf opgebouwd met HTML en CSS. Hierbij gebruik ik onder andere CSS Grid, Flexbox, CSS-nesting en media queries.

Het doel van dit project is om mijn vaardigheden te laten zien en steeds meer te leren over het ontwikkelen van websites.

HTML

Ik oefen met het opbouwen van webpagina's, HTML-elementen, links, formulieren en tabellen.

CSS

Ik oefen met het vormgeven van websites, kleuren, lettertypes, Flexbox en CSS Grid.
